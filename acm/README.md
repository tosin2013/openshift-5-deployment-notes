# Red Hat Advanced Cluster Management

Install ACM from the operator catalog on a hub cluster, then create a `MultiClusterHub`. Use the 2.17 book below. The OpenShift 4 notes target ACM 2.4, including an OpenShift 3.11 import. Do not apply those manifests to a hub or a managed cluster on OpenShift 5.

The 2.4-era notes, for reading only:

- [Cluster upgrade policies](https://github.com/tosin2013/openshift-4-deployment-notes/blob/master/acm/cluster-upgrade-policies.md)
- [Custom image endpoints](https://github.com/tosin2013/openshift-4-deployment-notes/blob/master/acm/set-custom-repo-endpoints.md)
- [Import a GKE cluster](https://github.com/tosin2013/openshift-4-deployment-notes/blob/master/acm/configure-gke-with-acm.md)
- [Import a Rancher cluster](https://github.com/tosin2013/openshift-4-deployment-notes/blob/master/acm/configure-rancher-with-acm.md)
- [Infrastructure configuration](https://github.com/tosin2013/openshift-4-deployment-notes/blob/master/acm/configure-infra-acm.md)

Product docs: [Get started with Red Hat Advanced Cluster Management](https://docs.redhat.com/en/documentation/red_hat_advanced_cluster_management_for_kubernetes/2.17/html/get_started/get-started-acm) (Red Hat Advanced Cluster Management for Kubernetes 2.17).

Check the support matrix for your OpenShift version before you subscribe. 2.17 was the newest book returned when these notes were linked.
